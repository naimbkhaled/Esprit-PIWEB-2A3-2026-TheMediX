# Gestion des utilisateurs (MVC PHP)

1. Importer `sql/database.sql` dans phpMyAdmin.
2. Adapter `config/database.php` si besoin (WAMP : root, mot de passe vide).
3. Copier le dossier dans `C:\wamp64\www\`.
4. Front office : http://localhost/gestion_users/view/front/register.php
5. Back office  : http://localhost/gestion_users/view/back/users.php
