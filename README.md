# MEDIX – Prevention & Care 🩺

MEDIX est une plateforme web qui regroupe plusieurs services de santé dans un seul endroit. Elle aide les utilisateurs à prendre des rendez-vous, consulter des informations médicales et suivre leur santé. Le projet contient aussi un espace spécial pour les personnes diabétiques.

## Description

Les principales fonctionnalités de MEDIX sont :

- Gestion des comptes (patient, médecin et administrateur).
- Prise de rendez-vous médicaux.
- Consultation d'articles de santé.
- Gestion du dossier médical.
- Forum et groupes de discussion.
- Messagerie et téléconsultation.
- Suivi de la glycémie et statistiques.
- Journal des repas, de l'insuline et des activités physiques.
- Rappels, alertes et contact d'urgence.
- Assistance par intelligence artificielle.

## Installation

1. Cloner le repository :

```bash
git clone https://github.com/naimbkhaled/the-MediX
```

2. Entrer dans le dossier :

```bash
cd TheMediX
```

3. Préparer l'environnement nécessaire au projet.
4. Configurer la base de données MySQL et importer le fichier SQL s'il est fourni.
5. Lancer le projet avec le serveur local utilisé.


## Utilisation

MEDIX contient deux espaces principaux :

### Espace général

Il permet de gérer les utilisateurs, prendre des rendez-vous, consulter des articles de santé, accéder au dossier médical et communiquer avec les médecins ou les autres utilisateurs.

### Espace diabète

Il permet de suivre la glycémie, enregistrer les repas et les doses d'insuline, noter les activités physiques et recevoir des rappels ou des alertes. Il propose aussi un espace de contact d'urgence.

L'intelligence artificielle peut aider à répondre aux questions générales et à analyser les tendances. Elle ne remplace pas l'avis d'un médecin.
