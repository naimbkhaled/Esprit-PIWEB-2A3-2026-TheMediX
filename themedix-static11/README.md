# The Medix - version statique (HTML / CSS / JS)

Deux projets : `frontoffice/` (patient) et `backoffice/` (médecin).
Aucun PHP : ouvrez simplement `index.html` dans le navigateur
(ou `python3 -m http.server` dans le dossier de votre choix).

    frontoffice/index.html   -> accueil patient
    backoffice/index.html    -> tableau de bord médecin

Le CSS et le JS sont identiques à la version PHP (copie conforme).
